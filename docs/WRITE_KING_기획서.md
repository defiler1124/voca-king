# WRITE KING 기획서

**작성일**: 2026-10-09

VOCA KING과 연동되는 영어 Writing 학습 서비스

---

## 1. 프로젝트 개요

**WRITE KING**은 영어 작문 능력을 체계적으로 향상시키는 학습 플랫폼입니다.

| 항목 | 내용 |
| --- | --- |
| 서비스명 | WRITE KING |
| 목표 | 영어 문장 작성 능력 향상 |
| 타겟 | 플로우어학원 학생 |
| 연동 | VOCA KING 회원 통합 |

**핵심 가치**
- 단어 학습(VOCA KING) → 문장 작성(WRITE KING) 연계 학습
- AI 기반 문법 교정 및 피드백
- 레벨별 단계적 학습 커리큘럼

---

## 2. VOCA KING 연동

**통합 회원 시스템**으로 두 서비스 간 원활한 연계 학습을 제공합니다.

| 연동 항목 | 설명 |
| --- | --- |
| 회원 DB 공유 | 동일한 User 테이블 사용, SSO 로그인 |
| 레벨 연동 | VOCA KING 레벨에 맞춰 Writing 난이도 조정 |
| 단어 활용 | 학습한 단어로 Writing 문제 자동 생성 |
| 통합 대시보드 | 단어 + Writing 학습 현황 통합 조회 |

**시너지 효과**
- 단어 암기 → 문장 작성으로 자연스러운 학습 흐름
- 학습한 단어를 직접 활용하여 기억 강화
- 통합 통계로 학습 성취도 측정

---

## 3. 핵심 기능

**3가지 학습 모드**로 단계별 Writing 능력 향상을 지원합니다.

| 모드 | 설명 | 예시 |
| --- | --- | --- |
| 빈칸 채우기 | 문장 내 빈칸에 알맞은 단어 입력 | I ___ to school every day. |
| 문장 완성 | 주어진 단어로 영어 문장 작성 | [학교, 가다] → I go to school. |
| 자유 작문 | 주제에 맞는 자유 영어 작문 | 주제: 나의 하루 일과 |

**AI 피드백 시스템**
- 문법 오류 자동 감지 및 교정 제안
- 더 자연스러운 표현 추천
- 레벨별 맞춤 피드백 난이도 조절
- 학습 이력 기반 취약점 분석

---

## 4. 학습 구조

VOCA KING과 동일한 **레벨/Day 구조**로 일관된 학습 경험을 제공합니다.

| 레벨 | 난이도 | 학습 내용 |
| --- | --- | --- |
| Lv.1~3 | 기초 | 간단한 문장 완성, 빈칸 채우기 |
| Lv.4~6 | 중급 | 복합문 작성, 문법 활용 |
| Lv.7~9 | 고급 | 에세이 작성, 의견 표현 |
| Lv.10~11 | 심화 | 자유 작문, 토론 글쓰기 |

**Day별 학습 흐름**
1. VOCA KING에서 해당 Day 단어 학습
2. WRITE KING에서 학습한 단어로 문장 연습
3. AI 피드백으로 교정 및 학습
4. 퍼펙트 테스트로 실력 확인

---

## 5. 기술 스택

VOCA KING과 동일한 기술 스택으로 **개발 및 운영 효율성**을 극대화합니다.

| 구분 | 기술 |
| --- | --- |
| Frontend | React 19, TypeScript, Vite, Zustand, Tailwind CSS |
| Backend | Spring Boot 3.2, Java 17, Spring Security, JWT |
| Database | MySQL 8.0 (회원 DB 공유) |
| AI | OpenAI API (GPT-4o-mini) 문법 교정 |
| 배포 | Vercel (Frontend), Railway (Backend) |

**아키텍처 특징**
- VOCA KING API 서버에 Writing 모듈 추가 (모놀리식)
- 회원/인증 로직 재사용
- 공통 컴포넌트 라이브러리 분리 가능
